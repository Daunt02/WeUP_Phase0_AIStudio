# Autogen Research Agents

This folder contains scaffolding for research agents that analyze the entire workspace, generate prompt-packs for GitHub Copilot, produce health reports, and assemble phased research whitepapers. It also includes a Crawl4AI suite for scraping event data for the WeUP project.

Structure:

- `agents/` — core agent implementations and runner
- `prompt_packs/` — prompt pack generators and templates
- `health/` — codebase health reporting
- `whitepapers/` — whitepaper generation helpers
- `REPORT.md` — detailed description of each agent and usage guidance
- `USAGE.md` — quick usage and examples

See `USAGE.md` for quick start instructions.
