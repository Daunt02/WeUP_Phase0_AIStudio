WeUP Phase 0.1 — Technical Requirements Document (TRD)
Feature: Promoter Profiles + Media Feed (Photos + Short Video)
Stack Alignment: .NET 8 + Vue 3 (Quasar) + gRPC/REST + Cloud Storage + Optional AI Agents
________________


0. Purpose
This TRD defines the technical architecture, system components, data models, APIs, infrastructure, and execution details required to implement:
Promoter Profiles + Media Feed System
This is implementation-ready and aligned to:
* Microservice-friendly architecture

* Event-driven extensibility

* Future AI orchestration (Autogen / Crawl4AI / vector DB)

3. Data Model (EF Core)
________________


3.1 PromoterProfile
public class PromoterProfile
{
    public Guid Id { get; set; }
    public string DisplayName { get; set; }
    public string Slug { get; set; }
    public string Bio { get; set; }


    public string ProfileImageUrl { get; set; }
    public string BannerImageUrl { get; set; }


    public string City { get; set; }


    public string InstagramUrl { get; set; }
    public string TikTokUrl { get; set; }
    public string WebsiteUrl { get; set; }


    public VerificationStatus VerificationStatus { get; set; }


    public DateTime CreatedAt { get; set; }
}
________________


3.2 MediaAsset
public class MediaAsset
{
    public Guid Id { get; set; }
    public Guid PromoterProfileId { get; set; }


    public MediaType MediaType { get; set; }


    public string Url { get; set; }
    public string ThumbnailUrl { get; set; }


    public string Caption { get; set; }


    public int? DurationSeconds { get; set; }


    public MediaStatus Status { get; set; }


    public DateTime CreatedAt { get; set; }
}
________________


3.3 FeedPost
public class FeedPost
{
    public Guid Id { get; set; }
    public Guid PromoterProfileId { get; set; }


    public string Title { get; set; }
    public string Body { get; set; }


    public PostType PostType { get; set; }


    public Guid? LinkedEventId { get; set; }


    public PostStatus Status { get; set; }


    public DateTime PublishedAt { get; set; }
}
________________


3.4 FeedPostMedia (Join Table)
public class FeedPostMedia
{
    public Guid FeedPostId { get; set; }
    public Guid MediaAssetId { get; set; }


    public int SortOrder { get; set; }
}

5. Media Processing Pipeline
________________


5.1 Upload Flow
Client → API → MediaService → Storage Provider
                        ↓
                Validation Layer
                        ↓
                Processing Layer
                        ↓
                 Metadata Persist
________________


5.2 Validation Layer
                     * MIME type check

                     * File size check

                     * Video duration check

                     * Malware scan (optional Phase 1)

________________


5.3 Processing Layer
Images
                        * Resize (multiple sizes)

                        * WebP conversion

                        * Thumbnail generation

Video
                           * Transcode to H.264

                           * Generate thumbnail frame

                           * Compress bitrate

________________
