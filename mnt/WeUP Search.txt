public static class SponsorVisualMapper
{
   public static SponsorVisualState Map(
       SponsorTier tier,
       float trustScore,
       bool isActive)
   {
       if (!isActive || tier == SponsorTier.None)
           return Disabled();


       var trustFactor = Math.Clamp(trustScore / 100f, 0f, 1f);


       // Sponsorship cannot amplify low trust excessively
       var trustGate = trustFactor < 0.4f ? 0.5f : 1.0f;


       return tier switch
       {
           SponsorTier.Bronze => new(
               HaloRadiusMultiplier: 1.05f * trustGate,
               HaloEmissionIntensity: 0.4f * trustGate,
               RotationSpeed: 0.2f,
               BeamHeight: 0f,
               Opacity: 0.6f * trustGate,
               RenderSponsorLayer: true),


           SponsorTier.Silver => new(
               1.10f * trustGate,
               0.6f * trustGate,
               0.4f,
               0.05f,
               0.75f * trustGate,
               true),


           SponsorTier.Gold => new(
               1.15f * trustGate,
               0.8f * trustGate,
               0.6f,
               0.1f,
               0.9f * trustGate,
               true),


           SponsorTier.Platinum => new(
               1.25f * trustGate,
               1.0f * trustGate,
               0.8f,
               0.15f,
               1.0f * trustGate,
               true),


           _ => Disabled()
       };
   }


   private static SponsorVisualState Disabled() =>
       new(1f, 0f, 0f, 0f, 0f, false);
}

1.1 Problem Space: Feed-Based Search Failure Modes
Modern search and discovery systems are predominantly ranked feed architectures (list-based retrieval + relevance scoring). These systems degrade under spatial and real-world intent because they assume:
* Linear information topology (items are ranked, not situated)
* Static relevance (decoupled from time and geography)
* Ad-driven ranking contamination (economic signals injected into relevance)
* Opaque scoring functions (non-auditable ranking pipelines)
Core failure modes
* Context collapse
   * “Search” becomes detached from physical reality (no geospatial grounding).
* Temporal blindness
   * Events, availability, and real-time state are flattened into static results.
* Economic signal corruption
   * Sponsored placement implicitly modifies perceived relevance.
* Cognitive overload
   * Infinite scroll induces low-confidence decision fatigue rather than resolution.
* Non-deterministic ranking opacity
   * Users cannot infer why results appear or change.
Net result: Search behaves as a probabilistic feed, not a deterministic discovery system.
