WeUP Phase 0 — Technical Requirements Document (TRD)
Scope: Deep infrastructure, OCR pipeline, parser pipeline, geocoding flow, map-serving backend, and operational architecture
Target Stack: .NET 8 + Vue 3 + Quasar + PostgreSQL + Redis + Object Storage + OCR/Parsing workers
________________


0. Document Intent
This TRD defines the technical design for WeUP Phase 0, where the platform ingests flyer images and converts them into structured events rendered on a geospatial discovery UI.
This document covers:
* infrastructure topology
* backend service decomposition
* OCR ingestion pipeline
* parsing and normalization pipeline
* geocoding strategy
* database design
* queue/event model
* observability and failure handling
* starter code for .NET services and OCR worker integration
This is the system-level execution spec for the MVP.
________________


1. Technical Objective
Build a system that can:
1. accept flyer uploads
2. store originals securely
3. run OCR on flyer content
4. parse extracted text into structured event records
5. geocode venue/address data
6. persist normalized events
7. expose query APIs for map/calendar rendering
8. support human/admin correction when OCR/parsing confidence is low
________________

7. Processing Pipeline
________________


7.1 Pipeline Stages
1. Upload accepted
2. Upload metadata persisted
3. File stored in object storage
4. OCR job queued
5. OCR worker extracts text
6. Raw OCR stored
7. Parse job queued
8. Parser extracts title/date/time/address/venue
9. Geocoder resolves lat/lng
10. Confidence scoring computed
11. Candidate auto-published or flagged
12. Public API returns event


________________


7.2 Confidence-Based Routing
Auto-publish threshold
Use a simple weighted model:
* OCR confidence: 30%
* title extraction confidence: 20%
* date/time confidence: 20%
* venue confidence: 10%
* geocode confidence: 20%
score >= 0.85  => auto publish
0.60 - 0.84    => needs admin review
< 0.60         => failed / needs manual correction


This is practical for Phase 0.
________________

17.4 Upload Command Handler
using Microsoft.AspNetCore.Http;
using WeUp.Application.Abstractions;
using WeUp.Domain.Entities;
using WeUp.Infrastructure.Persistence;


namespace WeUp.Application.Uploads;


public sealed class UploadFlyerHandler
{
    private static readonly HashSet<string> AllowedMimeTypes = new(StringComparer.OrdinalIgnoreCase)
    {
        "image/jpeg",
        "image/png",
        "image/webp"
    };


    private const long MaxFileSizeBytes = 10 * 1024 * 1024;


    private readonly WeUpDbContext _db;
    private readonly IObjectStorage _storage;
    private readonly IBackgroundJobQueue _queue;


    public UploadFlyerHandler(
        WeUpDbContext db,
        IObjectStorage storage,
        IBackgroundJobQueue queue)
    {
        _db = db;
        _storage = storage;
        _queue = queue;
    }


    public async Task<(Guid uploadId, Guid jobId)> HandleAsync(
        IFormFile file,
        string userId,
        CancellationToken ct)
    {
        if (file.Length <= 0)
            throw new InvalidOperationException("Empty file.");


        if (file.Length > MaxFileSizeBytes)
            throw new InvalidOperationException("File exceeds max size.");


        if (!AllowedMimeTypes.Contains(file.ContentType))
            throw new InvalidOperationException("Unsupported content type.");


        var uploadId = Guid.NewGuid();
        var objectKey = $"flyers/{DateTime.UtcNow:yyyy/MM/dd}/{uploadId}{Path.GetExtension(file.FileName)}";


        await using var readStream = file.OpenReadStream();
        await _storage.UploadAsync(readStream, objectKey, file.ContentType, ct);


        var upload = new FlyerUpload
        {
            Id = uploadId,
            OriginalFileName = file.FileName,
            StorageKey = objectKey,
            MimeType = file.ContentType,
            FileSizeBytes = file.Length,
            UploadedByUserId = userId
        };


        _db.FlyerUploads.Add(upload);
        await _db.SaveChangesAsync(ct);


        var jobId = Guid.NewGuid();
        await _queue.EnqueueOcrAsync(uploadId, ct);


        return (uploadId, jobId);
    }
}

using Microsoft.AspNetCore.Mvc;
using WeUp.Application.Uploads;


namespace WeUp.Api.Controllers;


[ApiController]
[Route("api/events")]

        _handler = handler;
    }


    [HttpPost("upload")]
    [RequestSizeLimit(10 * 1024 * 1024)]
    public async Task<IActionResult> Upload([FromForm] IFormFile file, CancellationToken ct)

        });
    }
}

18.2 OCR Worker Service
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
using WeUp.Application.Abstractions;
using WeUp.Infrastructure.Persistence;


namespace WeUp.Workers.Ocr;


public sealed class OcrWorkerService : BackgroundService
{
    private readonly IServiceProvider _serviceProvider;
    private readonly ILogger<OcrWorkerService> _logger;


    public OcrWorkerService(IServiceProvider serviceProvider, ILogger<OcrWorkerService> logger)
    {
        _serviceProvider = serviceProvider;
        _logger = logger;
    }


    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                using var scope = _serviceProvider.CreateScope();
                var queue = scope.ServiceProvider.GetRequiredService<IOcrQueueConsumer>();


                var nextUploadId = await queue.DequeueAsync(stoppingToken);
                if (nextUploadId is null)
                {
                    await Task.Delay(500, stoppingToken);
                    continue;
                }


                var db = scope.ServiceProvider.GetRequiredService<WeUpDbContext>();
                var storage = scope.ServiceProvider.GetRequiredService<IObjectStorage>();
                var ocrEngine = scope.ServiceProvider.GetRequiredService<IOcrEngine>();
                var parseQueue = scope.ServiceProvider.GetRequiredService<IBackgroundJobQueue>();


                var upload = await db.FlyerUploads.FirstOrDefaultAsync(x => x.Id == nextUploadId.Value, stoppingToken);
                if (upload is null)
                {
                    _logger.LogWarning("Upload not found: {UploadId}", nextUploadId);
                    continue;
                }


                await using var fileStream = await storage.OpenReadAsync(upload.StorageKey, stoppingToken);
                var result = await ocrEngine.ExtractTextAsync(fileStream, upload.OriginalFileName, stoppingToken);


                var existing = await db.OcrExtractions.FirstOrDefaultAsync(x => x.UploadId == upload.Id, stoppingToken);
                if (existing is null)
                {
                    db.OcrExtractions.Add(new OcrExtractionEntity
                    {
                        Id = Guid.NewGuid(),
                        UploadId = upload.Id,
                        RawText = result.RawText,
                        AverageConfidence = result.AverageConfidence,
                        EngineName = result.EngineName,
                        StructuredJson = result.StructuredPayloadJson
                    });
                }
                else
                {
                    existing.RawText = result.RawText;
                    existing.AverageConfidence = result.AverageConfidence;
                    existing.EngineName = result.EngineName;
                    existing.StructuredJson = result.StructuredPayloadJson;
                }


                await db.SaveChangesAsync(stoppingToken);
                await parseQueue.EnqueueParseAsync(upload.Id, stoppingToken);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "OCR worker iteration failed.");
                await Task.Delay(1000, stoppingToken);
            }
        }
    }

19.1 Parser Implementation
using System.Globalization;
using System.Text.RegularExpressions;
using WeUp.Application.Abstractions;


namespace WeUp.Infrastructure.Parsing;


public sealed class RegexFlyerParser : IFlyerParser
{
    private static readonly Regex TimeRangeRegex =
        new(@"(?<start>\d{1,2}(:\d{2})?\s?(AM|PM))\s*[-–]\s*(?<end>\d{1,2}(:\d{2})?\s?(AM|PM))",
            RegexOptions.IgnoreCase | RegexOptions.Compiled);


    private static readonly Regex DateRegex =
        new(@"(?<month>JAN|FEB|MAR|APR|MAY|JUN|JUL|AUG|SEP|OCT|NOV|DEC)[A-Z]*\s+(?<day>\d{1,2})",
            RegexOptions.IgnoreCase | RegexOptions.Compiled);


    private static readonly Regex AddressRegex =
        new(@"\d{2,6}\s+[A-Z0-9\s\.]+(ST|STREET|AVE|AVENUE|RD|ROAD|BLVD|DR|LANE|LN|WAY)\b.*",
            RegexOptions.IgnoreCase | RegexOptions.Compiled);


    public Task<ParsedFlyerResult> ParseAsync(string rawText, CancellationToken ct)
    {
        var lines = rawText
            .Split('\n', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries)
            .Where(x => !string.IsNullOrWhiteSpace(x))
            .ToList();


        var title = ExtractTitle(lines);
        var eventDate = ExtractDate(rawText);
        var (start, end, timeConfidence) = ExtractTimes(rawText);
        var address = ExtractAddress(lines);
        var venue = ExtractVenue(lines, address);


        var notes = new List<string>();
        if (title is null) notes.Add("Title not confidently resolved.");
        if (eventDate is null) notes.Add("Date not confidently resolved.");
        if (address is null) notes.Add("Address not confidently resolved.");


        return Task.FromResult(new ParsedFlyerResult
        {
            Title = title,
            EventDateLocal = eventDate,
            StartTimeLocal = start,
            EndTimeLocal = end,
            VenueName = venue,
            AddressRaw = address,
            TitleConfidence = title is null ? 0.30m : 0.85m,
            DateConfidence = eventDate is null ? 0.20m : 0.80m,
            TimeConfidence = timeConfidence,
            VenueConfidence = venue is null ? 0.35m : 0.75m,
            Notes = notes
        });
    }


    private static string? ExtractTitle(List<string> lines)
    {
        return lines
            .Where(x => x.Length is > 3 and < 80)
            .FirstOrDefault(x =>
                !x.Contains("AM", StringComparison.OrdinalIgnoreCase) &&
                !x.Contains("PM", StringComparison.OrdinalIgnoreCase) &&
                !char.IsDigit(x[0]));
    }


    private static DateTime? ExtractDate(string rawText)
    {
        var match = DateRegex.Match(rawText);
        if (!match.Success) return null;


        var monthToken = match.Groups["month"].Value[..3].ToUpperInvariant();
        var dayToken = match.Groups["day"].Value;


        if (!DateTime.TryParseExact(
                $"{monthToken} {dayToken} 2026",
                "MMM d yyyy",
                CultureInfo.InvariantCulture,
                DateTimeStyles.None,
                out var date))
        {
            return null;
        }


        return date;
    }


    private static (TimeOnly? start, TimeOnly? end, decimal confidence) ExtractTimes(string rawText)
    {
        var match = TimeRangeRegex.Match(rawText);
        if (!match.Success) return (null, null, 0.25m);


        static TimeOnly? ParseTime(string value)
        {
            var formats = new[] { "h tt", "h:mm tt", "hh tt", "hh:mm tt" };
            if (DateTime.TryParseExact(value.ToUpperInvariant(), formats, CultureInfo.InvariantCulture, DateTimeStyles.None, out var dt))
            {
                return TimeOnly.FromDateTime(dt);
            }


            return null;
        }


        var start = ParseTime(match.Groups["start"].Value.Replace(" ", ""));
        var end = ParseTime(match.Groups["end"].Value.Replace(" ", ""));


        return (start, end, (start is not null && end is not null) ? 0.85m : 0.45m);
    }


    private static string? ExtractAddress(List<string> lines)
    {
        foreach (var line in lines)
        {
            var match = AddressRegex.Match(line.ToUpperInvariant());
            if (match.Success) return line;
        }


        return null;
    }


    private static string? ExtractVenue(List<string> lines, string? address)
    {
        if (lines.Count == 0) return null;


        if (!string.IsNullOrWhiteSpace(address))
        {
            var idx = lines.FindIndex(x => x.Equals(address, StringComparison.OrdinalIgnoreCase));
            if (idx > 0) return lines[idx - 1];
        }


        return lines.Skip(1).FirstOrDefault(x => x.Length is > 3 and < 80);
    }
}

19.2 Parser Worker
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
using WeUp.Application.Abstractions;
using WeUp.Domain.Entities;
using WeUp.Infrastructure.Persistence;


namespace WeUp.Workers.Parser;


public sealed class ParserWorkerService : BackgroundService
{
    private readonly IServiceProvider _serviceProvider;
    private readonly ILogger<ParserWorkerService> _logger;


    public ParserWorkerService(IServiceProvider serviceProvider, ILogger<ParserWorkerService> logger)
    {
        _serviceProvider = serviceProvider;
        _logger = logger;
    }


    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                using var scope = _serviceProvider.CreateScope();
                var queue = scope.ServiceProvider.GetRequiredService<IParseQueueConsumer>();
                var uploadId = await queue.DequeueAsync(stoppingToken);


                if (uploadId is null)
                {
                    await Task.Delay(500, stoppingToken);
                    continue;
                }


                var db = scope.ServiceProvider.GetRequiredService<WeUpDbContext>();
                var parser = scope.ServiceProvider.GetRequiredService<IFlyerParser>();
                var geocoder = scope.ServiceProvider.GetRequiredService<IGeocodingService>();


                var ocr = await db.OcrExtractions.FirstOrDefaultAsync(x => x.UploadId == uploadId.Value, stoppingToken);
                var upload = await db.FlyerUploads.FirstOrDefaultAsync(x => x.Id == uploadId.Value, stoppingToken);


                if (ocr is null || upload is null)
                {
                    _logger.LogWarning("Missing OCR or upload for {UploadId}", uploadId);
                    continue;
                }


                var parsed = await parser.ParseAsync(ocr.RawText, stoppingToken);


                GeocodeResult? geocode = null;
                var geocodeInput = parsed.AddressRaw ?? parsed.VenueName;
                if (!string.IsNullOrWhiteSpace(geocodeInput))
                {
                    geocode = await geocoder.GeocodeAsync(geocodeInput, stoppingToken);
                }


                var parseConfidence = (
                    parsed.TitleConfidence * 0.20m +
                    parsed.DateConfidence * 0.20m +
                    parsed.TimeConfidence * 0.20m +
                    parsed.VenueConfidence * 0.10m +
                    (ocr.AverageConfidence ?? 0m) * 0.30m
                );


                var geocodeConfidence = geocode?.Confidence ?? 0m;
                var overall = parseConfidence + (geocodeConfidence * 0.20m);


                var candidate = await db.ParsedEventCandidates.FirstOrDefaultAsync(x => x.UploadId == uploadId.Value, stoppingToken);
                if (candidate is null)
                {
                    candidate = new ParsedEventCandidateEntity
                    {
                        Id = Guid.NewGuid(),
                        UploadId = uploadId.Value
                    };
                    db.ParsedEventCandidates.Add(candidate);
                }


                candidate.Title = parsed.Title;
                candidate.EventDateLocal = parsed.EventDateLocal;
                candidate.StartTimeLocal = parsed.StartTimeLocal;
                candidate.EndTimeLocal = parsed.EndTimeLocal;
                candidate.VenueName = parsed.VenueName;
                candidate.AddressRaw = geocode?.ResolvedAddress ?? parsed.AddressRaw;
                candidate.ParsingConfidence = parseConfidence;
                candidate.GeocodingConfidence = geocodeConfidence;
                candidate.ParseNotes = string.Join(Environment.NewLine, parsed.Notes);


                if (overall >= 0.85m && parsed.EventDateLocal is not null && parsed.StartTimeLocal is not null)
                {
                    candidate.ReviewStatus = 1; // AutoApproved


                    var start = parsed.EventDateLocal.Value.Date + parsed.StartTimeLocal.Value.ToTimeSpan();
                    DateTime? end = parsed.EndTimeLocal is null
                        ? null
                        : parsed.EventDateLocal.Value.Date + parsed.EndTimeLocal.Value.ToTimeSpan();


                    db.EventRecords.Add(new EventRecord
                    {
                        Id = Guid.NewGuid(),
                        SourceUploadId = upload.Id,
                        Title = parsed.Title ?? "Untitled Event",
                        StartDateTimeLocal = start,
                        EndDateTimeLocal = end,
                        VenueName = parsed.VenueName ?? string.Empty,
                        AddressLine = geocode?.ResolvedAddress ?? parsed.AddressRaw ?? string.Empty,
                        Latitude = geocode?.Latitude ?? 0,
                        Longitude = geocode?.Longitude ?? 0,
                        FlyerImageUrl = upload.StorageKey
                    });
                }
                else
                {
                    candidate.ReviewStatus = 2; // NeedsHumanReview
                }


                await db.SaveChangesAsync(stoppingToken);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Parser worker iteration failed.");
                await Task.Delay(1000, stoppingToken);
            }
        }
    }
}

using Microsoft.EntityFrameworkCore;

            .Where(x => x.State == 1 && x.StartDateTimeLocal >= from && x.StartDateTimeLocal <= to)

                Title = x.Title,
                StartDateTimeLocal = x.StartDateTimeLocal,
                EndDateTimeLocal = x.EndDateTimeLocal,
                VenueName = x.VenueName,
                AddressLine = x.AddressLine,
                Latitude = x.Latitude,
                Longitude = x.Longitude,
                FlyerImageUrl = x.FlyerImageUrl
            })
            .ToListAsync(ct);
    }

26. Blunt Assessment
The real Phase 0 technical risk is not the map.
It is data quality under noisy flyer input.
So the correct system shape is:
* deterministic first
* confidence-scored
* human-reviewable
* storage-safe
* operationally simple
That is what will actually survive first contact with real nightlife flyers.
