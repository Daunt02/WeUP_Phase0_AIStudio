WeUP Phase 0 Feature Addition
Promoter Profiles + Media Feed (Video + Multi-Photo Uploads)
This is a strong Phase 0.1 extension. It moves WeUP from flyer ingestion + discovery into identity-driven promotion. That matters because users do not just follow events—they follow who consistently curates good events.
What this feature should be
Add a Promoter Profile system where a promoter can:
* create a named profile

* upload a profile image / banner

* add multiple photos

* add short-form videos

* publish these into a profile feed

* attach media to:

   * their profile generally

   * a specific event

   * a venue relationship

   * a recurring brand identity

This gives WeUP three things immediately:
      1. Trust layer

Users begin to recognize promoters, not just random flyers.

      2. Retention loop

Users revisit profiles and feeds, not only one-off event pages.

      3. Monetization surface

Featured media, boosted profiles, premium uploads, profile analytics, verified promoter badges.

Product framing
New Phase 0 capability
Promoter Identity Feed
A promoter becomes a lightweight creator account with a public-facing media presence.
Core user story
As a promoter, I want a named profile where I can upload event photos and short videos so people can understand my vibe, trust my brand, and follow my events.
End-user story
As a user, I want to browse a promoter’s profile and media feed so I can decide whether their events match my taste.

Recommended Phase 0 scope
Keep this tight. Do not turn this into Instagram yet.
Must-have
         * named promoter profile

         * profile avatar

         * cover image / header

         * bio

         * social links

         * photo gallery

         * short video uploads

         * media feed timeline

         * event tagging

         * profile page visible to users

Should-have
            * follow / favorite promoter

            * featured media pin

            * profile verification badge (manual/admin-driven)

            * moderation queue for uploads

            * upload limits based on account tier

Not yet for Phase 0
               * live streaming

               * stories

               * DMs

               * public comments

               * complex creator monetization

               * long-form video hosting

               * algorithmic recommendation engine

That would bloat the MVP.

Exact feature model
1. Promoter Profile
Each promoter gets a public profile.
Fields
                  * Id

                  * DisplayName

                  * Slug

                  * Bio

                  * ProfileImageUrl

                  * BannerImageUrl

                  * City

                  * InstagramUrl

                  * TikTokUrl

                  * WebsiteUrl

                  * VerificationStatus

                  * IsActive

                  * CreatedAt

                  * UpdatedAt

Notes
                     * Slug should be unique and human-readable

Example: weup.com/promoters/houston-afterdark

                     * DisplayName is what users see

                     * verification should be manual at first

________________


2. Media Asset
Each uploaded piece of media is an asset.
Fields
                        * Id

                        * PromoterProfileId

                        * EventId nullable

                        * VenueId nullable

                        * MediaType (Photo, Video)

                        * Url

                        * ThumbnailUrl

                        * Caption

                        * AltText

                        * SortOrder

                        * VisibilityStatus (Draft, Published, Hidden, Flagged)

                        * DurationSeconds nullable

                        * Width

                        * Height

                        * FileSizeBytes

                        * CreatedAt

                        * UpdatedAt

Constraints
                           * photos: jpg, jpeg, png, webp

                           * videos: mp4, mov, webm

                           * max video length for Phase 0: 15–30 seconds

                           * max number of images per post or batch: 5–10

                           * always generate thumbnails

________________


3. Feed Post
Do not make media itself the feed item. Make a post that can contain media.
Fields
                              * Id

                              * PromoterProfileId

                              * Title

                              * Body

                              * LinkedEventId nullable

                              * PostType (General, EventPromo, Recap, VenueHighlight)

                              * PublishedAt

                              * Status (Draft, Published, Archived, Flagged)

                              * CreatedAt

                              * UpdatedAt

Child relation
FeedPostMedia
                                 * FeedPostId

                                 * MediaAssetId

                                 * SortOrder

This gives clean structure. One post can contain:
                                    * 1 video + 4 photos

                                    * 5 photos

                                    * just 1 photo

                                    * just 1 short promo clip

                                                                                 * virus/malware scan if available

Storage and backend design
Storage
Use object storage for media:
                                                                                          * Supabase Storage

                                                                                          * Cloudinary

                                                                                          * Firebase Storage

                                                                                          * S3-compatible bucket

For Phase 0, Cloudinary or Supabase Storage is practical.
Video handling
Do not serve raw uploads directly without transformation if avoidable.
You need:
                                                                                             * compression/transcoding

                                                                                             * thumbnail generation

                                                                                             * max duration enforcement

                                                                                             * mobile-friendly playback

For Phase 0, Cloudinary is the easiest path because it handles:
                                                                                                * image optimization

                                                                                                * video delivery

                                                                                                * transformations

                                                                                                * thumbnails

Concrete Phase 0 guardrails
To avoid feature sprawl, I would lock these rules:
                                                                                                                                                   * max 30 sec video

                                                                                                                                                   * max 10 media items per post

                                                                                                                                                   * no public comments

                                                                                                                                                   * no messaging

                                                                                                                                                   * no livestreaming

                                                                                                                                                   * no editing after publish beyond caption/media order

                                                                                                                                                   * one promoter profile per account at first

                                                                                                                                                   * manual verification only

That keeps the implementation realistic.
